# Choose Your Fighter & Python Practice 🎮

A collection of interactive command-line Python scripts and mini-games created while learning Python fundamentals. This repository features user input handling, conditional logic, functions, string manipulation, and mathematical operations.

---

## 🚀 Projects & Scripts Included

* **`ChooseYourFighter.py`:** An interactive character selection mini-game utilizing functions (`def`), user input, and robust conditional logic (`if`, `elif`, `else`) to unlock secret options and easter eggs.
* **`passwordcontrol.py`:** A lighthearted and humorous password validation script that checks user-defined string values against specific constraints.
* **`calculatingwithnumbers.py` (and number-string experiments):** Scripts exploring basic mathematical operations with numbers, type casting (`int()`), and testing what happens when numbers are treated as text/strings.
* **`helloworld.py` & `goodbyemars.py`:** Classic foundational greeting and exit scripts demonstrating basic output execution.

---

## 🛠️ Requirements

* **Python 3.x** installed on your system.
